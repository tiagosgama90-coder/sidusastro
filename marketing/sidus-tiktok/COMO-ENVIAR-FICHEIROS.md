# Como enviar os ficheiros para eu gerar o vídeo

Não consigo aceder à galeria do teu telemóvel. Tens de **subir os ficheiros para o GitHub** (5 min no telemóvel).

## Pasta

```
marketing/sidus-tiktok/assets/
```

## Ficheiros (nomes exactos)

| Ficheiro | O que é |
|----------|---------|
| `01-tarot.png` | Leitura Valete de Ouros |
| `02-horoscopo.png` | Horóscopo diário |
| `03-sonho-input.png` | Sonho com mar + chapéu vermelho |
| `04-sonho-cura.png` | Cura espiritual + meditação |
| `05-horas-1111.png` | Horas Iguais 11:11 |
| `06-oraculo.mp4` | Gravação do chat Oráculo |

## No telemóvel (GitHub app)

1. Abre o repo **sidusastro** no GitHub
2. Vai a `marketing/sidus-tiktok/assets/`
3. **Add file** → **Upload files**
4. Seleciona as 5 fotos + 1 vídeo
5. **Renomeia** para os nomes da tabela (muito importante)
6. Commit

## Quando estiver feito

Diz no chat: **"ficheiros enviados"** — eu corro o script e devolvo o `sidus-tiktok-pt-PT.mp4`.

## Voz

- **pt-PT Raquel** (português de Portugal, feminina)
- Para voz masculina: editar `VOICE = "pt-PT-DuarteNeural"` em `generate.py`
