---

## Descrição curta (1 parágrafo)

Sidus é uma aplicação web profissional de astrologia e bem-estar espiritual, construída com React + Vite, Firebase e Netlify Functions. Inclui mapa astral com Swiss Ephemeris e casas Placidus, tarot, sinastria, numerologia, interpretação de sonhos com IA, oráculo chat, biorritmo, horas iguais, PDF exportável, autenticação Google/email, pagamentos Stripe (compra única + subscrição premium) e AdSense. Interface em português e inglês. Ideal para empreendedores do nicho wellness, estúdios de astrologia ou agências que queiram um produto white-label.

## Stack técnica

- **Frontend:** React 19, Vite, React Router
- **Backend:** Netlify Functions (Node.js)
- **Auth/DB:** Firebase Authentication + Firestore
- **Pagamentos:** Stripe Checkout + Webhooks
- **IA:** Pollinations (grátis) + Groq/Gemini/OpenRouter opcionais
- **Deploy:** Netlify (config `netlify.toml` incluída)
- **Astrologia:** astronomy-engine, Swiss Ephemeris browser
