# BuiltByBit — Como publicar o pack Minecraft

## Passo 1 — Registo
https://builtbybit.com → Sign up (grátis) → verifica email → PayPal nas settings

## Passo 2 — Criar ZIP

No PC, dentro da pasta `minecraft-builtbybit`:

```bash
cd EconomyShopGUI-BalancedSurvival
zip -r ../BalancedSurvival-Shop-v1.zip sections shops INSTALL.md
```

Ou comprime manualmente: pasta `sections/`, pasta `shops/`, ficheiro `INSTALL.md`
